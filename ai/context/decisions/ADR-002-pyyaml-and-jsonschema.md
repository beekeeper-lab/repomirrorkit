# ADR-002: PyYAML (runtime) and jsonschema (dev)

**Status:** Accepted (2026-11-11, BEAN-073)

## Context
Screen specs are a YAML contract for rebuild agents (BEAN-073) and must be emitted with correct quoting/escaping; hand-rolled YAML emitters are a bug source. Tests validate generated JSON/YAML artifacts (OpenAPI, build manifest, screen specs, entity schemas) against JSON Schemas.

## Decision
- Add `pyyaml` as a runtime dependency (MIT, long-maintained, pure-wheel). Use `yaml.safe_dump` for output (sorted keys disabled, explicit ordering for determinism) and `yaml.safe_load` only; never `yaml.load`.
- Add `jsonschema` to the dev group (it was already present transitively through `openapi-spec-validator`; making it explicit documents the test dependency).

## Consequences
Two small, widely audited packages. Input to `safe_load` in tests is always generated by this tool.
